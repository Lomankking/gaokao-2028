# 2028 高考提分系统

面向安卓手机的离线优先学习记录网页。无需账号、服务器或付费 API；学习数据保存在当前浏览器的本地存储中。

## 项目结构

```text
dist/
  index.html       中文单页界面
  styles.css       手机优先样式
  app.js           页面交互与持久化
  model.mjs        数据结构、校验与统计
  manifest.webmanifest  安装信息
  sw.js            离线缓存
  icons/           桌面图标
tests/
  model.test.mjs   数据与统计测试
README.md          安卓使用说明与实施记录
```

## 实施计划

1. 建立项目、响应式页面骨架与版本化数据模型，检查静态文件与语法。
2. 完成六科成绩、每日任务、错题复习与知识点状态，运行数据逻辑测试。
3. 完成计时器、每周统计、JSON 备份恢复、PWA 离线缓存，运行完整测试。
4. 发布并验证网址，再补充安卓实际使用步骤。

## 数据约定

- 总分参考值为用户提供的 280/750，目标 620/750。
- 六科默认是语文、数学、英语、物理、化学、生物。第六科名称可在成绩页修改。
- 科目分数开始为空；只有六科都录入后才用最新分数计算实测总分。
- 复习间隔按完成次数依次为 1、3、7、14、30 天，并允许手动改日期。
- 周统计采用手机本地时区，周一至周日。

## 开发测试

在项目目录运行 `node --test tests/*.test.mjs`。网页文件可放在支持 HTTPS 的静态站点，也可在本机用静态服务器预览；PWA 安装与 Service Worker 需要 HTTPS 或 localhost。
